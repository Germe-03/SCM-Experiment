# Prompts für die CEO-Avatare

Stand 11.11.2026. Für Nano Banana. Pro Avatar zuerst das erste Bild mit dem vollen Prompt erzeugen. Die weiteren Bilder sind Bearbeitungen: das vorige Bild hochladen und den kurzen Prompt dazu geben, so bleibt es dieselbe Person.

Ein Avatar taucht in einem bestimmten Spieljahr mit einem bestimmten Alter auf. Wählbar ist er ab dann, frühestens mit 25. Mit 65 geht er in Pension. Bilder gibt es nur für Altersstufen, die er als wählbarer CEO erreicht: jung 25–39, mittel 40–54, alt 55–64.

Mit diesen Daten sind von Spieljahr 0 bis 51 immer mindestens 10 Avatare wählbar. 55 Bilder insgesamt.
